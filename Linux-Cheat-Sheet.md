# Linux Cheat Sheet

## Navigation Commands

- `pwd` – Shows the current directory
- `ls` – Lists files and folders
- `cd` – Changes directory
- `cd ..` – Goes to the parent directory

## File Commands

- `touch file.txt` – Creates a file
- `cat file.txt` – Displays file contents
- `mkdir folder` – Creates a folder
- `rm file.txt` – Deletes a file

## File Permissions

- `ls -l` – Shows file permissions
- `chmod +x file.txt` – Adds execute permission
- `chown` – Changes file ownership

## Package Management

- `sudo apt update` – Updates package information
- `apt --version` – Shows APT version
- `dpkg --version` – Shows DPKG version

## Networking Commands

- `ifconfig` – Shows network information
- `ping <IP>` – Tests network connectivity
- `netstat -an` – Shows network connections
- `traceroute <IP>` – Shows the network path

## Security Commands

- `nmap <IP>` – Scans for open ports
- `nmap -sV <IP>` – Identifies services and versions

## Important Note

All security testing commands were used only within the authorized private cybersecurity laboratory.
