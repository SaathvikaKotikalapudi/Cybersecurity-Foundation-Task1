## Internship
ApexPlanet Software Pvt. Ltd.

## Lab Network

Kali Linux and Metasploitable2 were connected through a private Host-Only network.

Metasploitable2 IP:

`192.168.56.101`

Connectivity was verified using the ping command.

## Security Tools Practiced

Wireshark was used to capture and analyze ICMP traffic.

Nmap was used to identify open ports and services on the Metasploitable2 machine.

Burp Suite was used to capture and inspect HTTP requests.

Netcat was attempted as a TCP connection test within the isolated lab.

## Learning Outcome

This task provided practical experience with cybersecurity fundamentals, Linux commands, networking, cryptography, and basic security testing tools in a controlled virtual environment.
