# Cybersecurity Notes

## CIA Triad

### Confidentiality
Ensures that information is accessible only to authorized users.

### Integrity
Ensures that data remains accurate and is not changed without authorization.

### Availability
Ensures that systems and data are available when required.

## Common Cyber Threats

- Phishing
- Malware
- Ransomware
- DDoS
- SQL Injection
- Brute Force Attacks

## Attack Vectors

- Social Engineering
- Wireless Attacks
- Insider Threats
- Malicious Links and Files

## Networking Basics

- DNS converts domain names into IP addresses.
- HTTP is used for web communication.
- HTTPS provides secure web communication using TLS.
- NAT allows private devices to access external networks.
- Subnetting divides a network into smaller networks.

## Cryptography

### Symmetric Encryption
Uses the same key for encryption and decryption.

Example: AES

### Asymmetric Encryption
Uses a public key and a private key.

Examples: RSA and ECC

### Hashing
Converts data into a fixed-length hash value.

Examples:
- MD5
- SHA-256

## Security Tools

### Wireshark
Used to capture and analyze network traffic.

### Nmap
Used to discover hosts, open ports, and services.

### Burp Suite
Used to intercept and analyze web requests.

### Netcat
Used for network connections and communication testing.

## Lab Environment

Kali Linux was used as the security testing machine and Metasploitable2 was used as the intentionally vulnerable target.

The machines communicated through a private Host-Only network.

All testing was performed only in the authorized isolated laboratory.
